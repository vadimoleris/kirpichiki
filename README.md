# Кирпичики

Карточки «иероглиф → значение» для пассивного узнавания китайских знаков.
Без тестов, таймеров и давления: листаешь большие карточки, все категории открыты сразу.

- Идея и постановка задачи — Вадим (vadimoleris)
- Реализация — ИИ Qwen (Alibaba)

## Колоды
- Кирпичики — 75 базовых компонентов: значение, самостоятельная форма, примеры в составе знаков
- Топ-100 — сотня самых частотных иероглифов (порядок близок к частотному)
- Вывески — 48 слов для навигации: аэропорт, метро, туалет, еда

План: Топ-300 и Топ-1000 — генерация скриптом из частотного списка и словаря.

## Управление
Стрелки / свайпы / клавиши ← →, клавиши 1–3 — категории. Позиция в каждой колоде запоминается.

## Добавить колоду
Дописать объект в DECKS в index.html: {id, name, cards:[{c, m, s?, x?}]} — больше ничего.

## Запуск и деплой
Локально: `python3 -m http.server`. Иконки — конвертер из pwa-tools,
проверка — pwa-check.py, деплой — deploy.sh.
